## 5. Kaise questions aate hain
Ye general pattern hai (mera experience + publicly shared pattern), koi asli question nahi. Har batch mein thoda badalta hai.

| Question | Level | Usually kya hota hai |
|---|---|---|
| 1 | Easy | Arrays, strings, hashing, simple greedy, sorting |
| 2 | Medium | Greedy ya DP (1D/2D), binary search on answer, prefix sums |
| 3 | Hard | Advanced DP (bitmask, DP on trees, digit DP), graphs (BFS/DFS, shortest path, DSU) |

- Questions **lambi story** mein likhe hote hain. Pehla kaam: story se asli problem nikaalna (input, output, constraints).
- **Constraints padho**: n ≤ 10^5 matlab O(n log n) chahiye, n ≤ 20 matlab bitmask chal sakta hai.
- Hidden test cases pe partial marks mil sakte hain, isliye pehle brute force submit karo, phir optimise.
- Jitne zyada questions poore solve, utna upar ka level (DSE → SP L1 → L2 → L3). Interview bhi count hota hai.

## 6. Kahan se padhna hai (is order mein)
5 din bache hain form ke liye, test usse baad hoga. Ye order follow karo:

1. **Language + STL/Collections** (1-2 din): vector/ArrayList, map/HashMap, set, priority_queue, sort with comparator.
2. **Arrays, strings, hashing, two pointers, sliding window**: Q1 yahi se aata hai.
3. **Sorting + binary search** (binary search on answer bhi).
4. **Greedy**: interval scheduling, activity selection type.
5. **Recursion → Dynamic Programming**: 1D (climbing stairs, house robber) → 2D (LCS, knapsack, grid paths) → partition DP → bitmask DP.
6. **Graphs**: BFS/DFS, connected components, Dijkstra, DSU, topological sort.
7. **Trees**: DFS on tree, DP on trees (subtree sums, diameter).

**Practice ka tarika:** roz 1 easy + 1 medium + har doosre din 1 hard. Hafte mein ek baar 3 ghante ka mock: 3 questions (easy, medium, hard) bina break ke.

## 7. Prep: ek Specialist Programmer ki salah
Ye meri personal salah hai, Infosys ki official guide nahi.

- **Sirf coding hai.** MCQ/aptitude ratne ka time coding pe lagao.
- **Topics:** arrays, strings, hashing, two pointers, sorting + binary search, greedy, recursion, **dynamic programming**, graphs (BFS/DFS) basics.
- **Time pe solve karo.** Roz 2-3 questions timer laga ke. 3 ghante lambe hote hain, practice mein bhi ek baar 3 ghante ka mock do.
- **Pehle brute force, phir optimise.** Partial solution bhi kuch na karne se better hai, edge cases (empty input, ek element, bada n) khud test karo.
- **Ek language pakki.** C++, Java ya Python, jisme STL/collections fast likh sako.
- **Interview:** apna test ka code aur apne projects samjha sako. Resume pe jo likha hai, wo poocha jayega.

Free practice: LeetCode (Easy → Medium, DP tag), HackerRank / CodeChef contests timer ke saath.
